# ZHOOR AIOS

A Linux-first AI operating environment under private development by Tariq Anjum.

**Status:** In development. Architecture documents and planning milestones do not establish that a product is released, generally available, or production-ready. Earlier documents use the former name **Hermes AIOS**.

This repository contains private development and architecture work. Public product overviews belong in [Odyssey](https://github.com/Tariq-Anjum/Odyssey); a public overview does not grant access to proprietary source.
