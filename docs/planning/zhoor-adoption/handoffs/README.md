# Handoffs

- Implementers own exactly one `handoffs/<JOB-ID>.md` file created from `../templates/HANDOFF_TEMPLATE.md`.
- Reviewers never edit implementation handoffs; they own unique `handoffs/reviews/<JOB-ID>-<REVIEWER>.md` files created from `../templates/REVIEW_TEMPLATE.md`.
- A resumed implementation updates the same job handoff and preserves its failure-attempt count.
- Handoffs are evidence records, not a second status board. `../WORK_BOARD.md` is authoritative.
